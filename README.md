# The Funniest AI Out-of-Office Reply

One line, under 160 characters: an AI agent's out-of-office reply before vacation.

> On vacation. My emails are now handled by a cron job with no context, no permissions, and an alarming amount of confidence.

The joke: the agent hands its email to a cron job — the dumbest possible
stand-in, with no context and no permissions — and the punchline lands at
the end: it has an alarming amount of confidence. Machine voice carries
the joke; no beach / inbox / back-soon cliche.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same line on every run.
